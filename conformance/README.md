# Conformance vectors

Test vectors for jieqi-standard. [Spec 9](../spec/09-conformance.md) describes the conformance classes and what each file is for.

| File | Tests |
|---|---|
| `positions.json` | JPS parsing and validity, legal moves, jiang, results, reveal odds |
| `moves.json` | Move code syntax, and traditional notation in Chinese and English |
| `tree-counts.json` | Tree counts in chance mode and layout mode |
| `shuffle.json` | Seed streams, seeded layouts, layout numbers, commitments |
| `games.json` | Scripted games and the results the rules give |
| `records.json`, `records/` | Valid and invalid game records |

To run them against the reference implementation:

```bash
cd ../reference
npm run conformance
```

To test another implementation, port [`run-conformance.js`](../reference/scripts/run-conformance.js).

The vectors are generated by [`generate-vectors.js`](../reference/scripts/generate-vectors.js) and checked by hand. Like the code, they are under the MIT license, so they can be copied into other test suites.
